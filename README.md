# ラブタイプ恋愛免許証 ジェネレーター

「ラブタイプ診断 恋の教科書」購入者限定の特典配布サイトです。
氏名とラブタイプを入力すると、完成済みの免許証画像に氏名・交付日が入り、
そのまま保存・SNSシェアできます。

ビルド不要の静的サイト（HTML / CSS / 素の JavaScript）なので、
GitHub Pages などにそのまま置けば動きます。

## ページ構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 入力ページ。「書籍購入者限定！特典お渡し所」の見出し・免許証の見本画像・入力フォームの3要素 |
| `result.html` | 結果ページ。氏名と交付日が入った免許証画像と、SNS拡散ボタン |

入力内容は URL のクエリで渡します（例: `result.html?name=ラブ+太郎&type=FCPE&date=2026-09-21`）。
サーバー不要で、リンクを踏めば同じ免許証が再現されます。

## 免許証画像の差し替え

**完成画像は `assets/licenses/<タイプコード>.png` に置くだけで切り替わります。**
コードを触る必要はありません。

現在配置済みなのは `FCPE.png`（忠犬ハチ公）のみです。
未配置のタイプは「準備中」のプレースホルダーが表示され、
結果ページにも制作中である旨の案内が出ます。

ファイル名・画像サイズ・位置調整のしかたは
[`assets/licenses/README.md`](assets/licenses/README.md) にまとめてあります。

## ファイル構成

```
index.html                  入力ページ
result.html                 結果ページ
assets/
  css/style.css             全体のスタイル
  js/types.js               16タイプの一覧（コード / タイプ名 / キャッチコピー）
  js/license.js             免許証画像の生成（完成画像 + 氏名・交付日の合成）
  js/form.js                入力ページの制御
  js/result.js              結果ページの制御・シェア処理
  licenses/<CODE>.png       タイプごとの完成画像 ← ここに差し替える
  licenses/README.md        差し替え手順
  img/sample-license.png    入力ページに出す見本画像
```

## SNSシェアの挙動

| ボタン | 挙動 |
| --- | --- |
| 画像つきでシェア | Web Share API で画像ファイルごと共有。対応端末（主にスマホ）でだけ表示されます |
| 画像を保存する | PNG をダウンロード |
| X / LINE / Facebook | 投稿文とサイトURLを渡して各シェア画面を開く（画像は手動添付） |
| 投稿文をコピー | 投稿文＋サイトURLをクリップボードへ |

X・LINE・Facebook のシェア URL には画像を添付できない仕様のため、
画像も一緒に流したい場合は「画像つきでシェア」か、保存してから手動添付という導線になります。

## ローカルでの確認

`file://` で開くと画像の読み込みが制限されるため、簡易サーバー経由で開いてください。

```bash
python3 -m http.server 8000
# http://localhost:8000/
```

## カスタマイズの入り口

| やりたいこと | 編集する場所 |
| --- | --- |
| 免許証のデザインを差し替える | `assets/licenses/<CODE>.png` を置く |
| 氏名・交付日の位置を直す | `assets/js/license.js` の `LAYOUT` / `LAYOUT_OVERRIDES` |
| タイプ名・キャッチコピーを直す | `assets/js/types.js` |
| シェア文・ハッシュタグを変える | `assets/js/result.js` の `HASHTAGS` と `caption` |
| 配色を変える | `assets/css/style.css` の `:root` |

## 注意点

- 画像生成は Canvas で行うため、**フォント（Google Fonts）の読み込み完了を待ってから描画**しています。
  オフラインだと端末標準のゴシック体にフォールバックします。
- OGP 画像は静的な見本画像を指しています。
  ユーザーごとの免許証を OGP に出すにはサーバーサイドでの画像生成が必要です。
