# ラブタイプ恋愛免許証 ジェネレーター

「ラブタイプ診断 恋の教科書」の特典配布サイトです。
氏名とラブタイプを入力すると、完成済みの免許証画像に氏名・交付日が入り、
そのまま保存・SNSシェアできます。

ビルド不要の静的サイト（HTML / CSS / 素の JavaScript）なので、
GitHub Pages などにそのまま置けば動きます。

## ページ構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 入力ページ。合言葉ゲート → 入力フォーム |
| `result.html` | 結果ページ。氏名と交付日が入った免許証画像と、SNS拡散ボタン |
| `tools/passcode.html` | 運営用。合言葉のハッシュを作るツール（公開時に消してよい） |
| `event.html` | ラブタイプ神社ポップアップの限定招待ページ（下記「イベント招待ページ」） |

入力内容は URL のクエリで渡します（例: `result.html?name=ラブ+太郎&type=FCPE`）。
サーバー不要で、リンクを踏めば同じ免許証が再現されます。
交付日は入力させず、アクセスした当日の日付が入ります。

## 免許証画像の差し替え

**完成画像は `assets/licenses/<タイプコード>.png` に置くだけで切り替わります。**
コードを触る必要はありません。

**16タイプすべて配置済みです。** 差し替えるときは同じファイル名で上書きしてください。
未配置のタイプがある場合は「準備中」のプレースホルダーが表示され、
結果ページにも制作中である旨の案内が出ます。

ファイル名・画像サイズ・位置調整のしかたは
[`assets/licenses/README.md`](assets/licenses/README.md) にまとめてあります。

## 取扱説明書（PDF）の差し替え

**PDFは `assets/manuals/<タイプコード>.pdf` に置くだけで切り替わります。**
16タイプすべて配置済みです。

利用者が保存したときのファイル名は、サイト側で
`書籍予約特典_◯◯の取扱説明書.pdf`（◯◯はタイプ名）に自動で付け替わるので、
置くファイルの名前はタイプコードのままで構いません。

対応表は [`assets/manuals/README.md`](assets/manuals/README.md) にあります。

## 合言葉ゲート（限定配布にする仕組み）

公式LINEで配布した合言葉を入力しないと、免許証を発行できないようにしています。
結果ページ（`result.html`）に直接アクセスした場合もブロックされます。

一度解除すると `localStorage` に記録され、次回以降は再入力不要です。

### 合言葉の変え方

合言葉は設定済みです。変更する場合は次の手順で差し替えます。

1. `tools/passcode.html` をブラウザで開く
2. 公式LINEで配布する合言葉を入力すると、貼り付ける1行が出る
3. `assets/js/gate.js` の `PASSCODE_SHA256 = ...` の行をそれで置き換える

コマンドでも出せます（半角小文字・空白なしの合言葉の場合）。

```bash
printf '%s' 'あたらしい合言葉' | shasum -a 256
```

入力は **全角・半角、大文字・小文字、前後の空白の違いを自動で吸収**します
（`　ＬｏｖｅＴｙｐｅ　` でも `lovetype` として判定）。
合言葉を変えると、解除済みの端末も自動的に再入力が必要になります。

### この方式の強度について

合言葉の平文はソースに含めていません（SHA-256 のハッシュだけを持っています）が、
**判定はブラウザ内で行うため、解析や総当たりで突破は可能です。**
「合言葉を受け取っていない人がうっかり使えない」程度の抑止力と考えてください。

厳密な会員制にしたい場合は、サーバー側の認証が必要です。
GitHub Pages にはアクセス制限機能が無いため、その場合は
Netlify / Vercel のパスワード保護や Cloudflare Access などへの移行を検討してください。

## イベント招待ページ（event.html）

ラブタイプ神社ポップアップの限定招待ページです。スマホ表示を基本に作っています。
関連ファイルは `assets/css/event.css`・`assets/js/event.js`・`assets/event/` です。

### 書き換える場所

設定はすべて `assets/js/event.js` の先頭にまとまっています。

| 設定 | 内容 |
| --- | --- |
| `RESERVE_URL` | 「参加予約をする」ボタンのリンク先（予約ツール TimeRex の URL） |
| `TIMER_HOURS` | 締め切りまでの時間（初期値 48） |
| `STORAGE_KEY` | 締め切り時刻の保存名。末尾の番号を変えると全員のタイマーが最初からになる |
| `GALLERY` | ギャラリーに並べる画像・動画の一覧 |

### Netlify で公開する

イベントページだけを Netlify で公開できます（特典サイトは含めません）。
`event.html` は `index.html` として置くので、URL はサイトのトップ（`https://○○.netlify.app/`）になります。

- 手作業で公開：`sh tools/build-netlify-event.sh` を実行してできた `dist-event/` フォルダを、
  https://app.netlify.com/drop にドラッグ＆ドロップ
- GitHub と連携して公開：Netlify で「Import from Git」からこのリポジトリを選ぶ。
  設定は `netlify.toml` に書いてあるので、そのまま公開できる

### 更新が反映されないとき

ブラウザが古い CSS / JS を使い続けないよう、`event.html` で読み込む
`event.css?v=…`・`event.js?v=…` に版番号を付けています。
`event.css` か `event.js` を書き換えたら、`event.html` のこの番号（日付など）も一緒に変えてください。

### 画像・動画の差し替え

- トップ画像：`assets/event/poster.jpg` を上書き
- ギャラリー：`assets/event/special-guide.jpg`（特別なご案内）と `cafe-pr.mp4`（コラボカフェPR動画）を置くだけで表示されます。
  まだ置いていない枠には「準備中」が表示されます。枚数やファイル名を変えるときは `GALLERY` を編集してください。
  動画のサムネイルを指定したいときは `poster` に画像のパスを書きます。

### カウントダウンの仕組み

- はじめてページを開いた時刻から 48 時間後を締め切りとして、ブラウザに保存します（localStorage と Cookie）。
  再度開いても、同じ締め切りに向けて残り時間が続きます。
- 残り時間が 0 になると「参加予約をする」ボタンが消え、「お申し込みの受付は終了しました」と表示されます。
- 保存先は**閲覧した端末・ブラウザごと**です。別の端末やブラウザで開いた場合、閲覧履歴を消した場合、
  プライベートブラウズで開いた場合は、そこから新たに 48 時間になります。
  これは静的サイトの仕組み上の限界で、厳密に締め切る必要がある場合は予約ツール側でも受付期限を設定してください。

## 検索エンジン対策

限定配布のサイトのため、以下で検索結果に出ないようにしています。

- `robots.txt` で全クローラーを `Disallow`
- 各ページの `<meta name="robots" content="noindex, nofollow, noarchive">`

ただし、これはクローラーへの「お願い」であって強制力はありません。
公開中は URL を知っていれば誰でもアクセスできる点は変わらないので、
限定運用は上記の合言葉ゲートと URL の扱いで担保する形になります。

## SNSシェアの挙動

| ボタン | 挙動 |
| --- | --- |
| 取扱説明書をダウンロードする | タイプごとのPDFを、日本語のファイル名に付け替えて保存 |
| 画像を保存する | 免許証のPNGをダウンロード |
| X / LINE | 投稿文とサイトURLを渡して各シェア画面を開く（画像は手動添付） |
| Instagram | 共有シートが使える端末ではそれを開く。使えない場合は画像を保存して、アプリで投稿してもらう |

X と LINE のシェア URL には画像を添付できない仕様のため、
画像も一緒に流したい場合は Instagram ボタン（共有シート）か、
保存してから手動添付という導線になります。

**Instagram について**：Instagram には X や LINE のような「投稿画面を開くURL」が公開されていません。
Web から投稿内容を用意して渡す方法が存在しないため、
スマホの共有シート（Instagram を選べる）経由か、画像を保存してアプリで投稿する導線にしています。
実質的にスマホ前提の機能なので、PC では「保存 → 手動で投稿」の案内が出ます。

## 入力ページのビジュアルについて

上部のビジュアル（バッジ・リボン・タイトルロゴ・書籍イラスト）は
デザインカンプから切り出した1枚の画像です（`assets/img/hero.*`、924 × 1055）。
カスタムのレタリングとイラストのため、CSSでは再現せず画像にしています。

**解像度**：表示サイズ 390 × 445 に対して 2.37倍の画素があり、
2倍密度の端末（多くのiPhone・Android）では十分にくっきり表示されます。
3倍密度の端末（iPhone の Pro / Max 系）では約1.3倍に引き伸ばされます。

そこまで詰めたい場合は、カンプ全体を **横1300px以上**（比率は 0.4621 のまま、
例：1300 × 2813）で書き出し、上から **52.725%** の位置で切ってください。
`hero.webp` と `hero.png` を置き換えるだけで、コードの変更は不要です
（`index.html` の `width` / `height` 属性だけ実寸に合わせてください）。

本より下の背景装飾も、同じカンプから切り出して `assets/img/below-bg.*` に置いています
（カードが乗る範囲とカンプのフッター文字は、重なっても目立たないよう均してあります）。

フォームのカード（白い枠・リボン・入力欄・ボタン）はHTML/CSSで組んでいるので、
文字はどの解像度でも鮮明で、文言の変更も自由にできます。
カードの左上・右下を横切るリボンは CSS で描いており、見出しは白いハロで
リボンの上でも読めるようにしています（カンプと同じ処理）。

## 注意点

- 書体は免許証アートワークと同じ **Rounded M+**（Google Fonts の
  「M PLUS Rounded 1c」として配信されているもの）を使っています。
  アートワークの文字は **中太（Medium＝ウェイト 500）** なので、画面の目立つ文字も 500 に揃えています。
- 画像生成は Canvas で行うため、**フォントの読み込み完了を待ってから描画**しています。
  オフラインだと端末標準のゴシック体にフォールバックします。
- OGP 画像は静的な見本画像を指しています。
  ユーザーごとの免許証を OGP に出すにはサーバーサイドでの画像生成が必要です。
