# 免許証の完成画像を差し替える

このフォルダに **タイプコード.png** を置くだけで、そのタイプの免許証が切り替わります。
コードの編集は不要です。

画像を置いた時点で、自動的に本番の免許証に切り替わります。

## 画像の条件

- **サイズ**：1080 × 1920 px（縦長・SNSストーリー比率）
  - 2倍の 2160 × 3840 px などでも動きます。縦横比が同じなら自動でスケールします。
- **形式**：PNG
- **レイアウト**：`FCPE.png`（忠犬ハチ公）と同じテンプレートにしてください。
  氏名欄・交付日欄の位置がズレると、文字の入る場所がズレます。

## サイトが書き込むのは 2か所だけ

| 項目 | 位置（1080×1920 基準） | 挙動 |
| --- | --- | --- |
| 氏名 | x:145 y:905 w:520 h:50 | 空欄の中央に書き込む |
| 交付日 | x:669 y:907 w:339 h:46 | いったん白で塗ってから「2026年 9月 21日交付」を書き直す |

**交付日欄について**：テンプレートに「2026年　月　日交付」と印刷されていても、
サイト側が白で塗りつぶしてから実際の日付を書き直すので、印字内容は気にしなくて大丈夫です。
逆に、この欄の背景が白以外（枠内に色や模様がある）デザインにすると塗りつぶしが目立ちます。

## 位置がズレたときの直し方

`assets/js/license.js` の先頭付近を編集します。

全タイプ共通でズラす場合は `LAYOUT` を変更：

```js
const LAYOUT = {
  name: { x: 145, y: 905, w: 520, h: 50, size: 36 },
  date: { x: 669, y: 907, w: 339, h: 46, size: 26, clear: '#ffffff' },
};
```

特定のタイプだけ違う場合は `LAYOUT_OVERRIDES` に差分だけ書きます：

```js
const LAYOUT_OVERRIDES = {
  LAPE: { name: { y: 912 } },            // 氏名欄だけ 7px 下げる
  FARO: { date: { clear: '#fff6f9' } },  // 交付日欄の下地が白じゃない場合
};
```

`size` は文字サイズの上限です。名前が長いときは枠内に収まるまで自動で縮みます。
