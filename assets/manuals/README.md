# 取扱説明書（PDF）を置く場所

このフォルダに **タイプコード.pdf** を置くだけで、
結果ページに「取扱説明書をダウンロードする」ボタンが出ます。コードの編集は不要です。

**16タイプすべて配置済みです。** 差し替えるときは同じファイル名で上書きしてください。
未配置のタイプは「取扱説明書は準備中です」と表示され、ボタンは出ません。

## 作業の手順

例：`カリスマバランサー書籍予約特典納品用.pdf` を配置する場合

```bash
cp "カリスマバランサー書籍予約特典納品用.pdf" assets/manuals/LARE.pdf
```

これだけで、利用者がボタンを押すと
`書籍予約特典_カリスマバランサーの取扱説明書.pdf` という名前で保存されます。

## 注意点

- ファイル名は **半角大文字のタイプコード** にしてください（`lare.pdf` は不可）。
- iOS の Safari では、PDFがダウンロードされずブラウザ内で開くことがあります。
  その場合、保存時のファイル名が指定どおりにならないことがあります（iOS側の仕様）。
- 容量が大きいPDFは表示までに時間がかかります。可能なら1ファイル5MB以下を目安に圧縮してください。
  （現在は1ファイル約3MB、16ファイル合計で約49MBです）
